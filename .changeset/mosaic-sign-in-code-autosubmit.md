Verification code screens on sign-in and sign-up no longer show a Continue button: the code submits itself once complete, with a "Verifying" status in place of the resend line while it is checked. The address the code went to appears under the description, with "Use a different email" or "Use a different phone number" beside "Use another method". When an account has several email addresses or phone numbers, "Use another method" lists each kind once, and the code screen lets you switch which address receives the code.
