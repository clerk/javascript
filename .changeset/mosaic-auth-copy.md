One voice for Mosaic's copy. Failures read "Couldn’t [do the thing]." followed by what to do next, without "Please", "Unable to" or "Something went wrong", across sign-in, sign-up, organizations, the user and organization profiles, API keys and the error catalog. Placeholders show an example or nothing, "Two-step verification" is used everywhere, resend countdowns read "Resend in 30s", file limits read "10 MB", and buttons name their action, such as "Send code" on the forgot-password step. Create organization and Invite members now have a short description.
