Add `Combobox.Media`, `Combobox.Label` and `Combobox.Detail` for composing a combobox option, styled through `.cl-combobox-option-media`, `.cl-combobox-option-label` and `.cl-combobox-option-detail`. `PhoneInput` builds its country options from these parts, which centers each country's name in its row and gives the flag, name and calling code targetable classes.
