# PasswordInput

The `PasswordInput` is a password field with a button that shows or hides what was typed. The button's accessible name switches between the two labels you pass, and every other input attribute, such as `name`, `autoComplete` and `value`, goes to the input.

It composes `InputGroup`, with a `Button` in the end slot. The root carries `.cl-password-input` with `data-size`, plus `data-visible` while the password is shown; the button carries `.cl-password-input-toggle`.
