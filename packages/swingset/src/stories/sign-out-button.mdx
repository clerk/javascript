```tsx
<SignOutButton />;
```

## Props

| Prop           | Type                   | Default                              | Description                                                                              |
| -------------- | ---------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------- |
| `redirectUrl`  | `string`               | the application's after-sign-out URL | Where to go after signing out.                                                           |
| `sessionId`    | `string`               | —                                    | Signs out this session only. Other signed-in sessions stay signed in.                    |
| `render`       | `ReactElement \| func` | —                                    | The element to render. The button's props are merged into it.                            |
| `children`     | `ReactNode`            | `'Sign out'`                         | The button's content. The default label is localized as `signOutButton.label`.           |
| `nativeButton` | `boolean`              | `true`                               | Set to `false` when `render` is not a `<button>`, to apply button semantics.             |
| `onClick`      | `MouseEventHandler`    | —                                    | Runs alongside signing out.                                                              |
| `fallback`     | `ReactNode`            | —                                    | Rendered while Clerk loads. Nothing renders once Clerk answers that nobody is signed in. |

Other `<button>` attributes pass through to the rendered element.

## Styling

The button emits no class. Style it with your own `className`, or through the element you pass to
`render`.

| Attribute       | Description                |
| --------------- | -------------------------- |
| `data-disabled` | Present while signing out. |

```css
.sign-out[data-disabled] {
  cursor: progress;
}
```
