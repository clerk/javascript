# UserProfileMfaSection

Display and manage two-step verification methods.

## Playground

Choose Add to set up a method. Use `000000` to see an incorrect-code error; other six-digit codes succeed. Row menus let you change the default, remove a method, or regenerate backup codes.

Account changes are simulated. Copy and Download use your browser’s clipboard and file downloads.
