## Usage

TaskChooseOrganization is available internally in Swingset. It is not yet exported from `@clerk/mosaic`.

```tsx
<TaskChooseOrganization redirectUrlComplete='/dashboard' />
```

| Prop                  | Type        | Default      | Description                                             |
| --------------------- | ----------- | ------------ | ------------------------------------------------------- |
| `redirectUrlComplete` | `string`    | — (required) | Where the user goes once the session has no tasks left. |
| `fallback`            | `ReactNode` | —            | Rendered while Clerk loads.                             |

It renders `fallback` while Clerk loads and nothing when nobody is signed in. When the session has no
`choose-organization` task, it sends the user on straight away.

## Choosing an organization

The list holds the organizations the user belongs to, then invitations, then suggestions, the same
rows as [OrganizationList](/misc/organization-list) without the personal account. Selecting an
organization makes it active and finishes the task. The user goes on to their next task, at its
`taskUrls` entry or the sign-in task route, or to `redirectUrlComplete` when none is left.

A user whose only membership is exclusive is not asked. Their organization is activated as soon as the
card has their memberships, and the list stays on screen with that row pending. If activating fails,
the error appears above the list and the user can choose again.

## Creating an organization

**Create new organization** replaces the list with the [CreateOrganization](/misc/create-organization)
form, and **Cancel** returns to it. Creating the organization makes it active and finishes the task.
When there is nothing to list, the form opens straight away and offers no way back.

  name='Empty'
  storyModule={TaskChooseOrganizationStories}
/>

When the instance has organization creation defaults, they fill the name and slug, and an advisory
about them appears above the form.

For users who cannot create organizations, the button is left out and the subtitle only offers to join.

/>

## Signing out

The foot of the card names the signed-in user by email address or username, with **Sign out**. Sign
out ends the session and goes to the after-sign-out URL. While other accounts stay signed in, it ends
only this one and goes to the after-multi-session-single-sign-out URL.

## Errors

A failed action shows its error above the list. Selecting an organization the user is no longer a
member of explains that, and suggests creating another one where the user may.
