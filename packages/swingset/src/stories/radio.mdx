# Radio

`Radio.Group` holds one choice out of several, and each `Radio.Item` is a styled native `<input type="radio">`. The group gives its items a shared `name` and checks the item whose `value` matches its own, controlled (`value` + `onValueChange`) or uncontrolled (`defaultValue`). Put each item in a [Field](/components/field) with `orientation='horizontal'` to give it a label and a description.

## Usage

```tsx
import { Field } from '@clerk/mosaic/components/field';
import { Radio } from '@clerk/mosaic/components/radio';

<Radio.Group
  aria-label='Plan'
  value={plan}
  onValueChange={setPlan}
>
  <Field.Root orientation='horizontal'>
    <Radio.Item value='monthly' />
    <Field.Label>Monthly</Field.Label>
  </Field.Root>
  <Field.Root orientation='horizontal'>
    <Radio.Item value='yearly' />
    <Field.Label>Yearly</Field.Label>
  </Field.Root>
</Radio.Group>;
```

## Parts

| Part            | Slot                    | Description                                                                                                      |
| --------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `Radio.Group`   | `radio-group`           | The `radiogroup`. Owns `value`, `defaultValue`, `onValueChange`, `name`, `disabled` and `layout`. `data-layout`. |
| `Radio.Item`    | `radio` / `radio-input` | One choice. `data-size`, `data-disabled`. Forwards its ref and input props to the input.                         |
| ↳ indicator     | `radio-indicator`       | The dot, shown while the item is checked.                                                                        |
| `Radio.Card`    | `radio-card` / `item`   | One choice laid out as an [Item](/components/item) row. `data-checked`, `data-disabled`.                         |
| ↳ media         | `item-media`            | `Radio.Media`, the icon or logo at the start of the card.                                                        |
| ↳ content       | `item-content`          | `Radio.Content`, which holds `Radio.Label` (`item-label`) and `Radio.Description` (`item-description`).          |
| `Radio.Section` | `radio-section`         | A `<fieldset>` of choices titled by `label`, with its own `layout`. `data-layout`.                               |
| ↳ label         | `text`                  | The `<legend>`.                                                                                                  |
| ↳ content       | `radio-section-content` | Lays out the section's choices.                                                                                  |

### Cards

`Radio.Card` is one choice laid out as an Item row: a `<label>` around a visually hidden radio, so a click anywhere on it picks the card. Fill it with `Radio.Media` and `Radio.Content`. Its `Radio.Label` names the radio, and an optional `Radio.Description` describes it. `layout='grid'` fits as many columns of cards as the width allows.

### Sections

One `Radio.Group` holds the value. `Radio.Section` renders a `<fieldset>` with its `label` as the `<legend>`, and its own `layout`. Sections sit further apart than the cards inside them. Every radio shares the group's `name`, so arrow keys move across sections and the picker is one Tab stop.
