# Profile permutations

Every pairing of switchers and profile shape, running on fixtures. Each example shares one account and
organization across its triggers, so switching in one updates the other and the profile.

`combined` defaults to `true` in two places: on `UserButton` it decides what the menu lists, and on
`MosaicProvider`'s `profile` it decides what the profile shows. `UserProfile` follows the provider unless
it sets `combined` itself. Custom pages and page order go on the provider too:

```tsx
<MosaicProvider
  profile={{
    combined: true,
    userProfileProps: { customPages },
    organizationProfileProps: { pageOrder },
  }}
>
  <OrganizationSwitcher />
  <UserButton combined={false} />
</MosaicProvider>
```

| --- | ---------------------------------------------- | -------- | ---------------------- |
| 1   | `UserButton` combined                          | Combined | None                   |
| 2   | `UserButton` combined                          | Separate | Profile opt-out        |
| 3   | `UserButton` user                              | Account  | Menu + profile opt-out |
