# Profile permutations

Exploration page: every pairing of switchers and profile shape, running on fixtures. Each example shares
one account and organization across its triggers, so switching in one updates the other and the profile.

Today `mode` on `UserButton` sets both the menu and the profile. `OrganizationSwitcher` always opens the
standalone organization profile.

The snippets show the proposed API, which is not implemented. `combined` defaults to `true` in two places:
on `UserButton` it decides what the menu lists, and on `MosaicProvider`'s `profile` it decides what the
profile shows.

| #   | Switchers                                      | Profile  | With the modal today                          | Proposed config        |
| --- | ---------------------------------------------- | -------- | --------------------------------------------- | ---------------------- |
| 1   | `UserButton` combined                          | Combined | Yes (the default)                             | None                   |
| 2   | `UserButton` combined                          | Separate | No                                            | Profile opt-out        |
| 3   | `UserButton` user                              | Account  | Yes                                           | Menu + profile opt-out |
| 4   | `UserButton` user                              | Combined | No                                            | Menu opt-out           |
| 5   | `UserButton` user + `OrganizationSwitcher`     | Separate | Yes                                           | Menu + profile opt-out |
| 6   | `UserButton` user + `OrganizationSwitcher`     | Combined | No                                            | Menu opt-out           |
| 7   | `OrganizationSwitcher`                         | Org      | Yes                                           | Profile opt-out        |
| 8   | `OrganizationSwitcher`                         | Combined | No                                            | None                   |
| 9   | `UserButton` combined + `OrganizationSwitcher` | Combined | No: the switcher opens the standalone profile | None                   |

The `No` rows can be approximated by routing with `userProfileUrl` and `organizationProfileUrl` to pages
that mount `<UserProfile />`.
