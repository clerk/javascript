# UserProfile

The complete user profile: a `Profile` whose navigation lists the Account, Security, Billing, and
API Keys pages it was given content for, then any pages of the consumer's own, in the order asked
for. Rendered inside a `profile` dialog it names it, carries its dismiss, and fills its height.
