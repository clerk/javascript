## Usage

```tsx
import { Card } from '@clerk/mosaic/components/card';

<Card.Root>
  <Card.Header>
    <Card.Title>Title</Card.Title>
    <Card.Description>Description</Card.Description>
  </Card.Header>
  <Card.Banner role='alert' color='negative'>{errorMessage}</Card.Banner>
  <Card.Content>Body content.</Card.Content>
  <Card.Footer>Footer actions</Card.Footer>
</Card.Root>
```

`Card.Media` goes first in `Card.Header`, above the title, for a logo, icon or image. It leaves 24px below it.

`Card.Header` takes `align='center'` to center its content.

`Card.Banner` sits between the header and the content and is always rendered. While its children hold a message, a `Banner` of the given `color` expands into it; once they are empty it collapses again. Give it `role='alert'` so the message is announced.

Buttons in `Card.Footer` are full width by default. Pass `fullWidth={false}` to opt out. A `Dialog.Popup` or `Popover.Popup` rendered inside the footer doesn't inherit this.
