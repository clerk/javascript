# MiddleTruncate

Prototype. Single-line text that truncates in the middle and keeps the last `tail` characters visible. Drag the bottom-right corner of each box to resize it. While the text overflows, hovering it (or focusing it, when it is not inside a control) shows the full value in a tooltip.
