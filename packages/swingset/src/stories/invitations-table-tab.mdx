# InvitationsTableTab

A controlled invitations table for the organization profile’s Invitations tab. The caller supplies the current page, role labels, loading state, and optional invite and revoke callbacks.

Render this view inside the organization members panel’s tab panel; the parent owns tab navigation.

## Example

### Legacy

The baseline table shows the invited email address, invitation date, role, and optional revoke action.
