# useDataTable

State manager for data tables. Tracks pagination, sorting, column filters, global filter, row selection, and expanded rows. Each state slice supports the controlled/uncontrolled pattern. Designed for server-side data: you supply the already-fetched page of rows, and the hook tracks which page, sort, and filters to request next.

## Usage

```tsx
import { useDataTable } from '@clerk/mosaic/primitives/hooks';

const {
  rows,
  pagination,
  nextPage,
  previousPage,
  getPageCount,
  rowSelection,
  toggleAllRowsSelected,
} = useDataTable({
  data: pageOfData,        // current page fetched from the server
  getRowId: row => row.id,
  totalCount: 1000,
  defaultPagination: { pageIndex: 0, pageSize: 20 },
  onPaginationChange: newPagination => {
    // re-fetch with the new page/size
  },
});
```

## Options

| Prop                    | Type                               | Default                          | Description                                     |
| ----------------------- | ---------------------------------- | -------------------------------- | ----------------------------------------------- |
| `data`                  | `TData[]`                          | required                         | Current page of rows                            |
| `getRowId`              | `(row, index) => string`           | `String(index)`                  | Stable row identifier                           |
| `getSubRows`            | `(row) => TData[] \| undefined`    | —                                | Child rows of a row                             |
| `getRowCanExpand`       | `(row) => boolean`                 | has sub-rows                     | Whether a row can expand                        |
| `isRowSelectable`       | `(row) => boolean`                 | every row                        | Whether a row can be selected                   |
| `selectionMode`         | `'none' \| 'single' \| 'multiple'` | `'multiple'`                     | How many rows can be selected                   |
| `totalCount`            | `number`                           | —                                | Total record count (used to compute page count) |
| `sorting`               | `SortingState`                     | —                                | Controlled sort state                           |
| `defaultSorting`        | `SortingState`                     | `[]`                             | Initial uncontrolled sort                       |
| `onSortingChange`       | `OnChangeFn<SortingState>`         | —                                | Called when sort changes                        |
| `columnFilters`         | `ColumnFiltersState`               | —                                | Controlled column filters                       |
| `defaultColumnFilters`  | `ColumnFiltersState`               | `[]`                             | Initial uncontrolled column filters             |
| `onColumnFiltersChange` | `OnChangeFn<ColumnFiltersState>`   | —                                | Called when column filters change               |
| `globalFilter`          | `string`                           | —                                | Controlled global search string                 |
| `defaultGlobalFilter`   | `string`                           | `''`                             | Initial uncontrolled global filter              |
| `onGlobalFilterChange`  | `OnChangeFn<string>`               | —                                | Called when global filter changes               |
| `pagination`            | `PaginationState`                  | —                                | Controlled pagination                           |
| `defaultPagination`     | `PaginationState`                  | `{ pageIndex: 0, pageSize: 10 }` | Initial uncontrolled pagination                 |
| `onPaginationChange`    | `OnChangeFn<PaginationState>`      | —                                | Called when pagination changes                  |
| `rowSelection`          | `RowSelectionState`                | —                                | Controlled row selection                        |
| `defaultRowSelection`   | `RowSelectionState`                | `{}`                             | Initial uncontrolled row selection              |
| `onRowSelectionChange`  | `OnChangeFn<RowSelectionState>`    | —                                | Called when selection changes                   |
| `expanded`              | `ExpandedState`                    | —                                | Controlled expanded rows                        |
| `defaultExpanded`       | `ExpandedState`                    | `{}`                             | Initial uncontrolled expanded rows              |
| `onExpandedChange`      | `OnChangeFn<ExpandedState>`        | —                                | Called when a row expands or collapses          |

## Return

### Rows

| Value  | Type                    | Description                                                                               |
| ------ | ----------------------- | ----------------------------------------------------------------------------------------- |
| `rows` | `DataTableRow<TData>[]` | The rows to render: top-level rows, with the children of each expanded row right after it |

Each `DataTableRow` has:

| Field                      | Type                                      | Description                                                                                                          |
| -------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `id`                       | `string`                                  | Stable row identifier                                                                                                |
| `original`                 | `TData`                                   | Original data item                                                                                                   |
| `depth`                    | `number`                                  | `0` for top-level rows, `1` for their children, and so on                                                            |
| `parentId`                 | `string \| null`                          | Id of the parent row, or `null` for top-level rows                                                                   |
| `index`                    | `number`                                  | Position among its siblings, from `0`                                                                                |
| `setSize`                  | `number`                                  | Number of siblings, including itself                                                                                 |
| `getCanSelect()`           | `() => boolean`                           | Whether this row can be selected                                                                                     |
| `getIsSelected()`          | `() => boolean`                           | Whether this row is selected                                                                                         |
| `toggleSelected(options?)` | `(options?: { range?: boolean }) => void` | Toggle selection for this row; with `range`, apply the toggle to every row between the last toggled row and this one |
| `getCanExpand()`           | `() => boolean`                           | Whether this row can expand                                                                                          |
| `getIsExpanded()`          | `() => boolean`                           | Whether this row is expanded                                                                                         |
| `toggleExpanded()`         | `() => void`                              | Expand or collapse this row                                                                                          |

### Pagination

| Value                  | Type                          | Description                          |
| ---------------------- | ----------------------------- | ------------------------------------ |
| `pagination`           | `PaginationState`             | Current `{ pageIndex, pageSize }`    |
| `setPagination`        | `OnChangeFn<PaginationState>` | Set pagination state                 |
| `nextPage()`           | `() => void`                  | Advance one page                     |
| `previousPage()`       | `() => void`                  | Go back one page                     |
| `setPageSize(n)`       | `(size: number) => void`      | Change page size and reset to page 0 |
| `getCanNextPage()`     | `() => boolean`               | Whether a next page exists           |
| `getCanPreviousPage()` | `() => boolean`               | Whether a previous page exists       |
| `getPageCount()`       | `() => number`                | `ceil(totalCount / pageSize)`        |

### Sorting

| Value        | Type                       | Description                                          |
| ------------ | -------------------------- | ---------------------------------------------------- |
| `sorting`    | `SortingState`             | Current sort: `Array<{ id: string; desc: boolean }>` |
| `setSorting` | `OnChangeFn<SortingState>` | Set sort state                                       |

### Filters

| Value              | Type                             | Description                  |
| ------------------ | -------------------------------- | ---------------------------- |
| `columnFilters`    | `ColumnFiltersState`             | Current column filters       |
| `setColumnFilters` | `OnChangeFn<ColumnFiltersState>` | Set column filters           |
| `globalFilter`     | `string`                         | Current global search string |
| `setGlobalFilter`  | `OnChangeFn<string>`             | Set global filter            |

### Row Selection

| Value                     | Type                            | Description                               |
| ------------------------- | ------------------------------- | ----------------------------------------- |
| `selectionMode`           | `SelectionMode`                 | The resolved selection mode               |
| `rowSelection`            | `RowSelectionState`             | `Record<string, boolean>` keyed by row id |
| `setRowSelection`         | `OnChangeFn<RowSelectionState>` | Set selection state                       |
| `getIsAllRowsSelected()`  | `() => boolean`                 | All current rows are selected             |
| `getIsSomeRowsSelected()` | `() => boolean`                 | Some (not all) rows are selected          |
| `toggleAllRowsSelected()` | `() => void`                    | Select all; clear if all already selected |

### Expanded Rows

| Value         | Type                        | Description                               |
| ------------- | --------------------------- | ----------------------------------------- |
| `expanded`    | `ExpandedState`             | `Record<string, boolean>` keyed by row id |
| `setExpanded` | `OnChangeFn<ExpandedState>` | Set expanded state                        |

## Types

```ts
type SortingState       = Array<{ id: string; desc: boolean }>;
type ColumnFiltersState = Array<{ id: string; value: unknown }>;
type PaginationState    = { pageIndex: number; pageSize: number };
type RowSelectionState  = Record<string, boolean>;
type ExpandedState      = Record<string, boolean>;
type SelectionMode      = 'none' | 'single' | 'multiple';
type Updater<T>         = T | ((old: T) => T);
type OnChangeFn<T>      = (updaterOrValue: Updater<T>) => void;
```
