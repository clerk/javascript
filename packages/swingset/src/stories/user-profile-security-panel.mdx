## Usage

`UserProfileSecurityPanel` renders the Security title with the password, passkeys, 2-step verification, and active devices sections. Each section shows itself only when the signed-in user and the instance settings call for it.

```tsx
import { UserProfileSecurityPanel } from '@clerk/mosaic/features/user-profile/user-profile-security-panel';

<UserProfileSecurityPanel />;
```

Pass sections as children to choose which ones render and in what order.

```tsx
import { UserProfileMfaSection } from '@clerk/mosaic/features/user-profile/user-profile-mfa-section/user-profile-mfa-section';
import { UserProfilePasswordSection } from '@clerk/mosaic/features/user-profile/user-profile-password-section/user-profile-password-section';
import { UserProfileSecurityPanel } from '@clerk/mosaic/features/user-profile/user-profile-security-panel';

<UserProfileSecurityPanel>
  <UserProfilePasswordSection />
  <UserProfileMfaSection />
</UserProfileSecurityPanel>;
```
