# UserProfileSecurityPanel

The security panel groups the available authentication methods and active devices. For a live
password section, render `UserProfileSecurityPanel`. It reads the password model and
passes content only when the password section is available or has a loading fallback,
so an empty Authentication section stays hidden. Fixtures pass
`<UserProfilePasswordSectionView {...props} />` directly as `passwordSlot`.
