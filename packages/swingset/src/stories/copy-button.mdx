# CopyButton

Puts a value on the clipboard and confirms it in a toast anchored to the button, which settles after
`resetAfter`. A toast rather than a tooltip because the confirmation is an event, not a description
of the control: it announces itself, `F6` reaches it and `Escape` dismisses it.
