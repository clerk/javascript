# CopyButton

Puts a value on the clipboard. A tooltip confirms the copy and settles after `resetAfter`. It
opens only on the copy, so the button carries no hover tooltip of its own.

The button keeps its name while the copy is fresh. A tooltip opened without the pointer is not
announced, so the outcome comes from a live region instead.
