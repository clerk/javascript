# OAuthConsent

Asks the signed-in user whether an OAuth application may access their account. `OAuthConsent` reads the client, scopes and redirect URI from the `client_id`, `scope` and `redirect_uri` URL parameters unless props set them, and posts the answer to Clerk with every URL parameter forwarded. When the application asks for `user:org:read`, the user picks which organization to grant. Each scope can show a checkbox with a label and a description; a required scope stays checked. It shows a loading card until the consent details load, and nothing when nobody is signed in.

## Usage

```tsx
import { OAuthConsent } from '@clerk/mosaic/features/oauth-consent/oauth-consent';

<OAuthConsent />;
```

## Props

| Prop            | Type     | Default                      |
| --------------- | -------- | ---------------------------- |
| `oauthClientId` | `string` | The `client_id` parameter    |
| `scope`         | `string` | The `scope` parameter        |
| `redirectUrl`   | `string` | The `redirect_uri` parameter |
