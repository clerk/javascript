# OrganizationProfileSecurityPanel

## Example

The overview lists the organization's security settings. A member who can manage enterprise connections, in an organization with self-serve SSO, sees each SSO connection with its domains and status. The row menu opens the connection in a dialog, activates or deactivates it, or removes it once the organization name is typed. A member who can manage the SSO bypass allow list sees it inline once the organization has an enterprise connection, laid out like the user profile's email section: the section title and a description of the allow list, an Add button, and the members below, 5 to a page.

### Manage a SAML connection

The dialog shows the connection's name, domains, the service provider values to copy into the identity provider, and the identity provider settings. Edit opens a dialog over it, which takes a metadata URL or a sign on URL, issuer and up to five signing certificates. The settings switches save as they change. Turning on Force re-authentication fails in this example, to show the row error.

### Allow list

The example allow list holds 36 members, so it spans eight pages. Remove in a row menu opens a confirmation dialog that names the member and their email. Confirming removes them and moves focus to the next row. Add opens a dialog that adds one member by email, or everyone with a role. Adding by email fails when no member has that address or the member is already listed. Adding by role skips members already listed, and reports members the server skips, such as members whose email domain no connection serves. Try `carol@acme.com`, `zed@acme.com`, or the Member role.
