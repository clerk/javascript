## Usage

```tsx
import { Waitlist } from '@clerk/mosaic';

<Waitlist />;
```

| Prop                   | Type        | Default                       | Description                                       |
| ---------------------- | ----------- | ----------------------------- | ------------------------------------------------- |
| `afterJoinWaitlistUrl` | `string`    | —                             | Where the user is sent two seconds after joining. |
| `signInUrl`            | `string`    | the application's sign-in URL | Where **Sign in** goes.                           |
| `fallback`             | `ReactNode` | —                             | Rendered while Clerk loads.                       |
