# SignUp

The standalone sign-up view. It reuses the sign-up screens the sign-in view shows in the combined flow, and adds the screens only a standalone sign-up has.

## Usage

The view renders its own `Card.Root` and shows one step at a time inside it. `step` says which step and carries that step's data; every other prop is shared across steps. `form` is one `useForm` holding every step's fields, and each step's form submits through `onSubmit`. `isPending` describes the current step's attempt, and `isDisabled` locks every control that would start another action, including while a social provider is pending. `errorMessage` is an error about the step's field; `globalErrorMessage` is an error about the whole step and shows in the card's banner. Leaving out a callback hides the control it drives: `onSignIn` for the sign-in link, `onCancel` for the step's secondary action, `onResend` for the resend line, `onEmailSupport` and `onJoinWaitlist` for the restricted screens.

```tsx
import { SignUpView } from '@clerk/mosaic/features/sign-up';

<SignUpView
  step={{ kind: 'details', purpose: 'start', fields: { emailAddress: { required: true } } }}
  applicationName='Acme'
  socialProviders={socialProviders}
  onSelectProvider={startProvider}
  form={form}
  onSubmit={submit}
  onCodeComplete={verify}
  isPending={isPending}
  isDisabled={isDisabled}
  onEditIdentifier={editIdentifier}
  onBack={back}
  canResend
/>;
```
