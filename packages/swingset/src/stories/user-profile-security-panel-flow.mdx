# Security panel flow

This story covers password, passkey, two-step verification, device, and account deletion actions.
The controls can add a delay, trigger an error, or require an identity check.

Errors can happen on the first request, during the identity check, or when the original request is
tried again. The mock controller handles these steps. The views only display the current state and
report what the user did.

## Legacy behavior covered

| Area             | What this story covers                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Panel            | Which sections and actions are available, plus device loading and error states                                                                 |
| Password         | Setting or changing a password, password rules, mismatched passwords, read-only passwords, and signing out other devices                       |
| Passkeys         | Creating a passkey right away, unsupported browsers, cancelled and failed requests, renaming, removal, and identity checks                     |
| Two-step         | Adding phone or authenticator methods, entering and resending codes, QR and setup keys, backup codes, defaults, removal rules, and errors      |
| Devices          | Active and pending devices, current and impersonated sessions, signing out one device, and the added “sign out all other devices” confirmation |
| Account deletion | Confirmation text, identity checks, failed requests, and where the user goes after deleting an account                                         |
| Identity checks  | Password, email, phone, passkey, authenticator, and backup-code methods, including selection, loading, help, and error states                  |

“Sign out all other devices” is an added flow. Regular dialogs close when clicking outside them.
Destructive confirmation dialogs do not.
