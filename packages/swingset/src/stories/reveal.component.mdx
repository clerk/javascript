# Reveal

Shows and hides its children with a height animation. Children mount when it opens and unmount once it has closed; while it closes they keep their last content and are inert. Mounted already open, it shows its children without an entrance.

/>

## Usage

```tsx
import { Reveal } from '@clerk/mosaic/components/reveal';

<Reveal open={expanded}>
  <Details />
</Reveal>;
```

A closed `Reveal` takes no space, so put the spacing around the content inside it, as a margin on the revealed content, rather than as a gap on the parent.

## Parts

| Part     | Stable slot class | Description                                                            |
| -------- | ----------------- | ---------------------------------------------------------------------- |
| `Reveal` | `.cl-reveal`      | `div` whose grid row animates between closed and the content's height. |

## Styling

`Reveal` carries `data-open` while open and `data-closed` while closing, plus `data-starting-style` and `data-ending-style` for the frames an entrance starts from and an exit animates to. It reads `--cl-duration-slow`, `--cl-ease-enter` and `--cl-ease-in-out`, and snaps open and closed under `prefers-reduced-motion`. Override `.cl-reveal` from a CSS layer that wins over `@clerk/mosaic/styles.css`:

```css
@import '@clerk/mosaic/styles.css' layer(components);

@layer overrides {
  .cl-reveal {
    transition-duration: 400ms;
  }
}
```
