# Section

## Usage

```tsx
import { Section } from '@clerk/mosaic/components/section';

<Section.Root>
  <Section.Group>
    <Section.Header>
      <Section.Title>Account</Section.Title>
      <Section.Actions>{control}</Section.Actions>
    </Section.Header>
    <Section.Body>
      <Section.Row>
        <Section.Item>
          <Section.Media>{icon}</Section.Media>
          <Section.Content>
            <Section.Label>Name</Section.Label>
            <Section.Description>Shown throughout the application.</Section.Description>
          </Section.Content>
          <Section.Actions>{control}</Section.Actions>
        </Section.Item>
      </Section.Row>
    </Section.Body>
  </Section.Group>
</Section.Root>
```

`Section.Root` holds one topic and stacks its cards. It has no title of its own; pass `aria-label`
to expose it as a named region.

`Section.Group` is a card. `Section.Header` holds its `Section.Title`, an optional
`Section.Description`, and optional `Section.Actions`; the card takes its accessible name from
the title. `Section.Body` wraps everything under the header and draws the divider between the two.

Inside the body, a `Section.Row` holds one setting as a `Section.Item`. `Section.Items` renders a
list of values, one `Section.Item` per entry, and each item becomes a list item. Items lay out
optional media, flexible content, and trailing actions. `Section.Media` accepts `sm`, `md`, `lg`,
and `xl` sizes.

When a row offers no action, `Section.Note` takes the place of its `Section.Actions` to say why — it
sits directly in `Section.Item` and holds the trailing slot itself. Its `icon` prop renders into a
fixed leading slot sized to the text, for a provider logo or a lock.

`Section.Group` is a query container named `cl-section`, so rows can adapt to the card's width.
`Section.Item` accepts `wrap`, which moves the actions under the content when the card is narrower
than `26rem`. `sectionCompactStyles.hidden` and `sectionCompactStyles.only` toggle inline content at
the same width.

`Section.Group skeleton` turns a card into its loading state, drawn from placeholder content you
pass in. The title, label, and description each render one bar, as wide as their text (held to one
line). Media render as a filled block, and actions draw nothing and hold the height of a small
control. A part can also take `skeleton` on its own, or `skeleton={false}` to stay as content inside
a skeleton card. A skeleton card is inert and hidden from assistive technology, so pair it with a
visually hidden status message. A highlight sweeps left to right across each placeholder. When to
show the skeleton, and for how long, is up to the caller.

`Section.Title` renders at the level from the nearest `HeadingLevelProvider`, or `h2` outside one.
On a page, put the sections in `Panel.Sections` so the card titles sit one level below the page
title. See [Panel](/components/panel) and [Heading](/components/heading).

## Parts

| Part                  | Element     | Class                     | Notes                                                           |
| --------------------- | ----------- | ------------------------- | --------------------------------------------------------------- |
| `Section.Root`        | `<section>` | `.cl-section`             | Stacks cards. Unnamed unless given `aria-label`.                |
| `Section.Group`       | `<div>`     | `.cl-section-group`       | The card, with `role='group'` named by its title.               |
| `Section.Header`      | `<div>`     | `.cl-section-header`      | Title, optional description, optional actions.                  |
| `Section.Title`       | heading     | `.cl-section-title`       | The card's heading.                                             |
| `Section.Body`        | `<div>`     | `.cl-section-body`        | The card's content; draws the divider under the header.         |
| `Section.Row`         | `<div>`     | `.cl-section-row`         | One setting.                                                    |
| `Section.Items`       | `<ul>`      | `.cl-section-items`       | A list of values.                                               |
| `Section.Item`        | `<div>`     | `.cl-section-item`        | Media, content, and actions on one line. `<li>` inside `Items`. |
| `Section.Media`       | `<div>`     | `.cl-section-media`       | Reflects `data-size`.                                           |
| `Section.Content`     | `<div>`     | `.cl-section-content`     | Label and description.                                          |
| `Section.Label`       | `<div>`     | `.cl-section-label`       |                                                                 |
| `Section.Description` | `<div>`     | `.cl-section-description` |                                                                 |
| `Section.Actions`     | `<div>`     | `.cl-section-actions`     |                                                                 |
| `Section.Error`       | `<p>`       | `.cl-section-error`       | A row-level message, placed beside the item inside the row.     |

Every part takes `xstyle`, `ref`, and `render` along with its element's props. Items and content
inside `Section.Items` reflect `data-nested`.
