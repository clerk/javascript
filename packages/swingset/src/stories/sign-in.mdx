## Usage

The view renders one step at a time inside a `Card.Root` and reports every interaction through plain callbacks. `combined` switches the start card to the sign-in-or-up copy and hides the sign-up link. The code, backup code, method picker, and help steps are the reverification feature's step views.

```tsx
import { Card } from '@clerk/mosaic/components/card';
import { SignInView } from '@clerk/mosaic/features/sign-in';

<Card.Root>
  <SignInView
    step={step}
    combined
    applicationName='Acme'
    socialProviders={providers}
    {...callbacks}
  />
</Card.Root>;
```
