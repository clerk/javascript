# Icon

Icon renders a glyph from Mosaic's icon set, passed as `glyph` and imported from `@clerk/mosaic/icons/glyphs/<name>`. It sizes through the `size` variant. Monochrome glyphs inherit `currentColor`; device illustrations keep their Figma palettes. Any glyph can be swapped per name through the `icons` prop on `MosaicProvider`. Mosaic's styling applies to an override just like the built-in glyph — so swapped icons stay visually consistent — and the override also carries the `.cl-icon` class and `data-size` attribute for targeting.

## Usage

```tsx
import { Icon } from '@clerk/mosaic/components/icon';
import { ChevronRight } from '@clerk/mosaic/icons/glyphs/chevron-right';

<Icon glyph={ChevronRight} />;
```

### Overriding a glyph

Pass `icons` to `MosaicProvider` to replace a glyph by name. The override is a plain element of any type, not just an `svg`; Mosaic clones it with the resolved sizing `className` and `data-size`, keeping any class the element already had. The replacement only supplies its own content.
