# Icon

Icon renders a named glyph from Mosaic's registry. The artwork follows the [Mosaic icon set in Figma](https://www.figma.com/design/yt5qKlfNyIIdaKaMoav1v2/Clerk-Mosaic-2.0?node-id=8004-6488), alongside the filled [device illustrations](https://www.figma.com/design/yt5qKlfNyIIdaKaMoav1v2/Clerk-Mosaic-2.0?node-id=163-1747) and dedicated security glyphs. Monochrome icons inherit color; device illustrations keep their own palettes. `MosaicProvider` can replace any glyph by name.

## Usage

<Usage
  component='Icon'
  module='@clerk/mosaic/components/icon'
  props={{ name: 'chevron-right', role: 'img', 'aria-label': 'Next' }}
/>

SVG props pass through to the rendered element. Use `aria-hidden` for a decorative icon beside text. Give a standalone meaningful icon `role="img"` and an `aria-label`. For an icon-only button, label the button and hide its icon.

Set `placement="inline-start"` or `placement="inline-end"` when the icon leads or trails text. It reflects `data-icon` so containers such as Button can adjust their padding. Placement follows the writing direction and applies no styling of its own.

Built-in glyphs forward `ref` to their SVG. For a provider override, put the ref on the replacement element itself; Icon does not forward its ref to an override.

## Examples

### Sizes

With the default spacing tokens, `sm`, `md`, and `lg` render at 14, 16, and 20px. `inherit` uses `1em`; the example below inherits a 24px font size. `xstyle` can override the size atoms.

Size controls the canvas. Artwork keeps its source proportions: `checkmark-small`, `checkmark-circle`, `user-circle-plus`, and `arrow-up-right` intentionally occupy less space within that canvas.

### Names

The gallery includes every registered name. `support` is the rescue ring; `dotted-square` is the separate artwork in Figma's second frame named “support.” Filled device illustrations and dedicated security glyphs are distinct from similarly named outline icons. The building preserves its source paths with corrected placement to prevent clipping.

### Overriding a glyph

Pass `icons` to `MosaicProvider` to replace a glyph by its registered name. The example replaces `chevron-right` with the existing arrow glyph; `chevron-left` keeps its default artwork.

Overrides are React elements. Mosaic applies `.cl-icon`, sizing, `data-size`, placement, and SVG props from the Icon call site, while keeping the replacement's own class names. A custom component must pass those props to its root element. Overrides can also be non-SVG elements.
