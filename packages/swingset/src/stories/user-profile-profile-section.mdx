# UserProfileProfileSection

The profile image, name and username, composed with `Section`. Upload and remove act on the image in
place; Edit name opens a dialog for the first and last name, and Edit username opens one seeded with
the saved username. With no username yet, the row offers Add instead.

## Name managed by a connection

An enterprise connection owns the name, so the Name row names who manages it in place of an edit
action. The connection's logo leads the label, or a generic lock when it ships none.
