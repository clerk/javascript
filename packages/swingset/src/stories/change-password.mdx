## Usage

The fields for choosing a new password: the new password, its confirmation, and the option to sign out of other devices. Changing a password in the user profile and resetting a forgotten one at sign-in both render it. The caller supplies the surface around it: the title, the banner, and the actions.

Each password field takes the props `form.register` returns, and `fields` takes the form's field state. `passwordFeedback` is a hint about the new password, such as its strength. It shows while the field has focus, and an `info` hint turns into an error once the user leaves the field. A field error from the form shows instead of the hint. A hidden `username` input carries `identifier`, so a password manager saves the new password for the right account. Leaving out `signOutOfOtherSessionsDescription` shows the checkbox label alone.

```tsx
import { ChangePassword } from '@clerk/mosaic/blocks/change-password';

<Card.Content render={<Form id={form.id} onSubmit={form.handleSubmit} />}>
  <ChangePassword
    messages={messages}
    identifier={identifier}
    newPassword={form.register('newPassword')}
    confirmPassword={form.register('confirmPassword')}
    fields={form.fields}
    signOutOfOtherSessions={form.values.signOutOfOtherSessions}
    onSignOutOfOtherSessionsChange={checked => form.setValue('signOutOfOtherSessions', checked)}
    passwordFeedback={passwordFeedback}
    disabled={form.isSubmitting}
  />
</Card.Content>;
```
