# UserProfilePhoneSection

The user's phone numbers, composed with `Section`. Each row's menu verifies, sets the primary
number, or removes it.

Add phone opens the flow using local state and simulated requests. Entering or pasting six digits
submits automatically. Use `000000` to see an incorrect-code error.
