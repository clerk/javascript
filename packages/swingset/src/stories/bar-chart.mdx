# BarChart

A stacked bar chart over a category or time axis, with values above and below zero. It is a
**headless** primitive: D3 computes the stacks and scales, Canvas paints the bars, SVG draws the
grid, axes and marks, and the primitive handles pointer and keyboard selection. It ships **no
styles**. Every part, including the Canvas bars, takes its appearance from your CSS.

## Example

Move the pointer over the chart, or focus it and use the arrow keys, to select a week. The chart is
unstyled, so the bars take the inherited text color and the grid and zero lines have no stroke.

## Usage

```tsx
import { BarChart } from '@clerk/mosaic/primitives/bar-chart';

const layout = BarChart.useStackedBarLayout({ data, series, index });

<BarChart.Root
  layout={layout}
  height={320}
  aria-label='Weekly sign-ups'
>
  <BarChart.Grid>
    {lines =>
      lines.map(line => (
        <BarChart.GridLine
          key={line.value}
          line={line}
        />
      ))
    }
  </BarChart.Grid>
  <BarChart.StackedBars isBarActive={isBarActive}>
    <BarChart.Bar className='bar' />
    <BarChart.ProjectionOutline />
    <BarChart.ZeroLine />
  </BarChart.StackedBars>
  <BarChart.YAxis>
    {ticks =>
      ticks.map(tick => (
        <BarChart.YTick
          key={tick.value}
          tick={tick}
        />
      ))
    }
  </BarChart.YAxis>
  <BarChart.XAxis>
    {ticks =>
      ticks.map(tick => (
        <BarChart.XTick
          key={tick.key}
          tick={tick}
        />
      ))
    }
  </BarChart.XAxis>
  <BarChart.BarSelection onActivate={openPeriod}>
    <BarChart.Cursor />
    <BarChart.Tooltip>{active => <PeriodSummary row={active.datum} />}</BarChart.Tooltip>
  </BarChart.BarSelection>
</BarChart.Root>;
```

`series` is an ordered list of `{ key, value }`, where `value` reads a number from a row. `index`
returns each row's unique category key. Memoize `series`, `index` and `isBarActive`.

### Dimming bars

`isBarActive` marks every other bar `data-inactive`, so CSS can dim it. This keeps one week's
positive section at full color:

```tsx
const isBarActive = useCallback(
  (bar: BarIdentity<Row>) => bar.datum.week === selectedWeek && bar.positive,
  [selectedWeek],
);

<BarChart.StackedBars isBarActive={isBarActive}>
  <BarChart.Bar className='bar' />
</BarChart.StackedBars>;
```

### Projection

`projection` draws a projected total above one category's positive stack. The fill is painted
with `BarChart.Bar`'s `data-projection` color, and `BarChart.ProjectionOutline` draws its outline.
It is drawn only when `value` is above that category's stack.

```tsx
const layout = BarChart.useStackedBarLayout({
  data,
  series,
  index,
  projection: { datumIndex: data.length - 1, value: 130 },
});
```

## Parts

| Part                         | Default Element | Description                                                         |
| ---------------------------- | --------------- | ------------------------------------------------------------------- |
| `BarChart.Root`              | `<div>`         | Measures the container and provides the layout                      |
| `BarChart.Grid`              | `<svg>`         | Holds the grid lines                                                |
| `BarChart.GridLine`          | `<line>`        | One line across the plot at a Y tick                                |
| `BarChart.StackedBars`       | `<div>`         | Paints the bars on Canvas and holds an SVG for the marks above them |
| `BarChart.Bar`               | `<g>`           | Hidden. Its computed style paints the bars                          |
| `BarChart.ProjectionOutline` | `<rect>`        | Outlines the projected bar                                          |
| `BarChart.ZeroLine`          | `<line>`        | The line at zero                                                    |
| `BarChart.YAxis`             | `<svg>`         | Holds the Y tick labels                                             |
| `BarChart.YTick`             | `<text>`        | One Y tick label                                                    |
| `BarChart.XAxis`             | `<svg>`         | Holds the category labels                                           |
| `BarChart.XTick`             | `<text>`        | One category label                                                  |
| `BarChart.BarSelection`      | `<div>`         | Pointer and keyboard selection                                      |
| `BarChart.Cursor`            | `<div>`         | Covers the selected category's band                                 |
| `BarChart.Tooltip`           | `<div>`         | The tooltip for the selected bar, portaled                          |

Every part accepts a `render` prop and the standard attributes of its default element. Every part
throws outside `BarChart.Root`. `BarChart.Bar` and `BarChart.ProjectionOutline` throw outside
`BarChart.StackedBars`, and `BarChart.Cursor` and `BarChart.Tooltip` throw outside
`BarChart.BarSelection`.

## Props

### `BarChart.useStackedBarLayout`

| Prop                     | Type                                                         | Default           | Description                                            |
| ------------------------ | ------------------------------------------------------------ | ----------------- | ------------------------------------------------------ |
| <code>data</code>        | <code>readonly TDatum[]</code>                               | — (required)      | The rows                                               |
| <code>series</code>      | <code>readonly BarSeries&lt;TDatum&gt;[]</code>              | — (required)      | Stack order and each series' value                     |
| <code>index</code>       | <code>(datum: TDatum, index: number) => string</code>        | — (required)      | A unique, stable category key                          |
| <code>categoryGap</code> | <code>number</code>                                          | <code>0.28</code> | Fraction of each band left empty                       |
| <code>projection</code>  | <code>&#123; datumIndex: number; value: number &#125;</code> | —                 | A projected total, drawn when it rises above its stack |

### `BarChart.Root`

| Prop                    | Type                                    | Default                    | Description                                       |
| ----------------------- | --------------------------------------- | -------------------------- | ------------------------------------------------- |
| <code>layout</code>     | <code>StackedBarLayoutSource</code>     | — (required)               | The result of `BarChart.useStackedBarLayout`      |
| <code>aria-label</code> | <code>string</code>                     | — (required)               | Labels the bars image and the interaction surface |
| <code>height</code>     | <code>number \| string</code>           | <code>500</code>           | The container height                              |
| <code>margin</code>     | <code>Partial&lt;ChartMargin&gt;</code> | <code>8, 16, 36, 52</code> | Space for the axes: top, right, bottom, left      |

### `BarChart.StackedBars`

| Prop                     | Type                                                     | Default          | Description                                            |
| ------------------------ | -------------------------------------------------------- | ---------------- | ------------------------------------------------------ |
| <code>isBarActive</code> | <code>(bar: BarIdentity&lt;TDatum&gt;) => boolean</code> | every bar active | Returns false for a bar styled through `data-inactive` |

### `BarChart.XAxis`

| Prop                | Type                                         | Default                 | Description                                                    |
| ------------------- | -------------------------------------------- | ----------------------- | -------------------------------------------------------------- |
| <code>ticks</code>  | <code>'category' \| 'calendar'</code>        | <code>'category'</code> | `calendar` labels calendar boundaries for long UTC date ranges |
| <code>format</code> | <code>(key: string) => string \| null</code> | the key                 | Labels a category, or returns null to omit it                  |

`BarChart.YAxis` takes `format` (`(value: number) => ReactNode`, locale number by default).
`BarChart.Grid`, `BarChart.YAxis` and `BarChart.XAxis` take a `children` function that receives
their items. `BarChart.GridLine` takes `line`, and `BarChart.YTick` and `BarChart.XTick` take
`tick`.

### `BarChart.BarSelection`

| Prop                        | Type                                                   | Default | Description                                         |
| --------------------------- | ------------------------------------------------------ | ------- | --------------------------------------------------- |
| <code>onActiveChange</code> | <code>(active: BarSelection \| null) => void</code>    | —       | Receives the selected category and section, or null |
| <code>onActivate</code>     | <code>(active: ActiveBar&lt;TDatum&gt;) => void</code> | —       | Called on click, Enter or Space                     |
| <code>formatCategory</code> | <code>(key: string) => string \| null</code>           | the key | Names a period in keyboard announcements            |

### `BarChart.Tooltip`

| Prop                     | Type                                                        | Default      | Description                                 |
| ------------------------ | ----------------------------------------------------------- | ------------ | ------------------------------------------- |
| <code>children</code>    | <code>(active: ActiveBar&lt;TDatum&gt;) => ReactNode</code> | — (required) | Content for the selected bar; null hides it |
| <code>boundaryRef</code> | <code>RefObject&lt;HTMLElement \| null&gt;</code>           | the chart    | Element the tooltip stays inside            |

## Styling

`BarChart.Bar` styles the Canvas. Before each paint the chart sets these attributes on it, reads
its computed `color`, and paints with it:

| Attribute         | Description                      |
| ----------------- | -------------------------------- |
| `data-series`     | The series key of the bar        |
| `data-inactive`   | The bar is outside `isBarActive` |
| `data-projection` | The projection fill              |

Its `max-width` caps the bar width, `row-gap` sets the gap between segments, its top corner radius
rounds a stack's outer end and its bottom corner radius rounds every other corner. Without
`BarChart.Bar`, nothing is painted.

| Attribute                     | Applies To   | Description                                                    |
| ----------------------------- | ------------ | -------------------------------------------------------------- |
| `data-chart-interaction-mode` | Root         | `pending`, `interactive` or `visual-only`                      |
| `data-active`                 | XTick        | Present while the tick's period is selected                    |
| `data-active-section`         | BarSelection | `positive` or `negative` on the interaction surface            |
| `data-side`                   | Tooltip      | `left` or `right` of the period, or `bottom` when pinned       |
| `data-open` / `data-closed`   | Tooltip      | Open state, with `data-starting-style` and `data-ending-style` |

```css
.bar[data-series='signups'] {
  --bar: #7c3aed;
}
.bar {
  max-width: 32px;
  row-gap: 2px;
  border-radius: 4px 4px 2px 2px;
  color: var(--bar);
}
.bar[data-inactive] {
  color: color-mix(in srgb, var(--bar) 40%, transparent);
}
.bar[data-projection] {
  color: #d4d4d4;
}
```
