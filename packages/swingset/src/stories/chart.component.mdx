# Chart

The styled Mosaic chart: the parts of the headless [`Chart` primitive](/primitives/chart) with Mosaic
styles applied, plus a legend and tooltip content. It inherits the primitive's pointer and keyboard
selection and its announcements.

## Usage

`Chart.useBarChart` takes rows, a category key and series that each name a color, and returns the
chart for `Chart.Root`. Each part renders a sensible default with no children, so a full chart is
one line per part. Define `series` and `index` at module level or memoize them.

```tsx
import { Chart, type ChartSeries } from '@clerk/mosaic/components/chart';

const gain = (percent: number) => `color-mix(in oklab, var(--cl-color-chart-1) ${percent}%, white)`;
const faintText = 'color-mix(in oklab, var(--cl-color-foreground-secondary) 50%, var(--cl-color-surface))';

const series: ChartSeries<Week>[] = [
  { key: 'retained', label: 'Retained', color: gain(100), value: week => week.retained },
  { key: 'reactivated', label: 'Reactivated', color: gain(60), value: week => week.reactivated },
  { key: 'new', label: 'New', color: gain(30), value: week => week.new },
  { key: 'retainedChurned', label: 'Retained churned', color: 'var(--cl-color-foreground)', value: week => week.retainedChurned },
  { key: 'reactivatedChurned', label: 'Reactivated churned', color: 'var(--cl-color-foreground-secondary)', value: week => week.reactivatedChurned },
  { key: 'newChurned', label: 'New churned', color: faintText, value: week => week.newChurned },
];
const getWeek = (week: Week) => week.week;

function ActiveUsers({ weeks, projected }: { weeks: Week[]; projected: number }) {
  const chart = Chart.useBarChart({
    data: weeks,
    index: getWeek,
    series,
    projection: { datumIndex: weeks.length - 1, value: projected, label: 'Projected' },
  });
  return (
    <Chart.Root
      chart={chart}
      aria-label='Weekly active users'
    >
      <Chart.Legend />
      <Chart.Grid />
      <Chart.Bars>
        <Chart.Bar />
        <Chart.ProjectionOutline />
      </Chart.Bars>
      <Chart.YAxis />
      <Chart.XAxis ticks='calendar' />
      <Chart.Selection>
        <Chart.Cursor />
        <Chart.Tooltip />
      </Chart.Selection>
    </Chart.Root>
  );
}
```

Each series names its color: a palette slot from `1` to `6`, which reads `--cl-color-chart-<n>`, or
any CSS color. The legend, the bars and the tooltip read that one field, so filtering the list never
recolors the series that remain. Give unrelated series separate slots. Give related series, such as
a measure and its churn, steps of one hue, as above, so the chart reads as gains and losses rather
than six categories.

Besides `data`, `index` and `series`, the hook takes `highlight`, `projection`, `formatValue`,
`formatCategory`, `categoryGap`, `margin`, `selection`, `onSelectionChange` and `onActivate`. Keys in
UTC date form, such as `2026-01-05`, format as dates; pass `formatCategory` for anything else. The
default `margin` leaves room for both axes, so pass a smaller one when you leave an axis out.

Children customize a part. `Chart.Tooltip` takes a render function that receives
`{ active, heading, metrics, rows }`, and `Chart.Legend` takes one that renders each item's label.
`Chart.Grid`, `Chart.YAxis` and `Chart.XAxis` take the primitive's render functions. Outside a chart,
`Chart.Legend items={series}` places the legend elsewhere, such as beside an Export button.

```tsx
<Chart.Tooltip<ActiveBar<Week>>>
  {({ active, heading, metrics, rows }) => (
    <Chart.TooltipContent
      heading={heading}
      metrics={[...metrics, { label: 'Total', value: active.datum.signups + active.datum.returning }]}
      rows={rows}
    />
  )}
</Chart.Tooltip>
```

### Palette

The six slots in order. They pass the data-viz contrast and color-blind checks against the surface
in light and dark mode for neighbours in this order. Avoid slot 2 beside 4, 2 beside 6 and 3 beside 5
in one stack.

### Highlight

`highlight` keeps the matching bars at full strength and dims the rest with an opaque mix toward
`--cl-color-surface`, so grid lines never show through. Here the selection drives it. Without
`highlight`, hovering shows the band and tooltip and dims nothing.

### Projection

A projected total for one row, drawn as an opaque neutral fill with a dashed outline when it rises
above the row's stack. A `label` adds it to the legend and the tooltip.

### Empty

Without rows the chart shows an `EmptyState` over the plot and sets `data-state="empty"`. Replace it
with `renderEmptyState` on `Chart.Root`. Loading is the owner's: render a `Skeleton` of the same
`height`.

### Render error

When the Canvas cannot paint, the chart sets `data-state="error"`, calls `onRenderError` and shows a
negative `Banner` with a retry that mounts a fresh Canvas.

## Parts

| Part                      | Class                          | Description                                                                                                      |
| ------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `Chart.Root`              | `.cl-chart`                    | The legend above the plot (`.cl-chart-plot`). Sets the series colors and owns the empty and error states.        |
| `Chart.Legend`            | `.cl-chart-legend`             | The series, then a labelled projection as a dashed entry. Items are `.cl-chart-legend-item`.                     |
| `Chart.Grid`              | `.cl-chart-grid`               | Dotted lines (`.cl-chart-grid-line`) at the Y ticks, below the bars.                                             |
| `Chart.YLine`             | `.cl-chart-y-line`             | A solid line at a value, such as zero.                                                                           |
| `Chart.Bars`              | `.cl-chart-bars`               | The Canvas, above the hover band. Defaults to `Chart.Bar`, `Chart.ProjectionOutline` and a zero line.            |
| `Chart.Bar`               | `.cl-chart-bar`                | The hidden element the Canvas reads for color and geometry.                                                      |
| `Chart.ProjectionOutline` | `.cl-chart-projection-outline` | A dashed outline around the projected total, painted from this hidden element's `stroke` and `stroke-dasharray`. |
| `Chart.YAxis`             | `.cl-chart-y-axis`             | Value labels (`Chart.YTick`, `.cl-chart-y-tick`).                                                                |
| `Chart.XAxis`             | `.cl-chart-x-axis`             | Category labels (`Chart.XTick`, `.cl-chart-x-tick`).                                                             |
| `Chart.Selection`         | `.cl-chart-selection`          | Pointer and keyboard selection. Defaults to `Chart.Cursor` and `Chart.Tooltip`.                                  |
| `Chart.Cursor`            | `.cl-chart-cursor`             | The hover band, behind the bars.                                                                                 |
| `Chart.Tooltip`           | `.cl-chart-tooltip`            | The tooltip surface. Defaults to `Chart.TooltipContent` with one row per series.                                 |
| `Chart.TooltipContent`    | `.cl-chart-tooltip-content`    | Heading (`.cl-chart-tooltip-heading`), metrics (`.cl-chart-tooltip-metric`) and rows (`.cl-chart-tooltip-row`).  |

## Styling

`.cl-chart` carries `data-chart="bar"` and `data-state`: `ready`, `empty` or `error`. Legend items and
tooltip rows carry `data-series` with the series key, and swatches (`.cl-chart-swatch`) carry
`data-swatch`: `square`, `line` or `dashed`. A legend item with a description carries
`data-described`. Ticks carry `data-active` while their period is selected.

The palette is `--cl-color-chart-1` to `--cl-color-chart-6`. Dimmed bars keep 40% of their color,
mixed with `--cl-color-surface`, so they stay opaque over the grid. The grid lines, the tick labels
and the tooltip background read `--cl-color-border`, `--cl-color-foreground-secondary` and
`--cl-color-surface`. To restyle them in one chart, target the part's class.

```css
.cl-chart {
  --cl-color-chart-1: oklch(0.55 0.2 160);
}
.cl-chart-grid-line {
  stroke: oklch(0.9 0 0);
  stroke-dasharray: none;
}
```
