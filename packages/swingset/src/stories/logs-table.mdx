# LogsTable

A table of the active organization's activity: who did what, from which IP address, and when. It lists events newest first, with search across members, IP addresses, and event types, and page navigation. Selecting an event opens a dialog with its full details. Members without permission to read logs see a notice in place of the table. `perPage` sets how many events a page lists, 10 by default.
