# RequestsTableTab

A controlled requests table for the organization profile’s Requests tab. The caller supplies the current page, loading state, optional names and avatars, and independent accept and decline callbacks. Each row can hold its actions with `pendingAction` while a decision is in flight.

Accepting or declining a request opens a confirmation dialog. The dialog awaits the action callback and keeps failures visible. After a successful removal, focus moves to a surviving row action or a toolbar control.

Render this view inside the organization members panel’s tab panel; the parent owns tab navigation.
