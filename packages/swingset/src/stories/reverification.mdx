## Usage

`useReverify` reads Clerk state and drives the reverification flow. Run the request through `reverify` inside a `useAction` action. `prompt` stays `null` until a challenge is ready, so the caller can keep showing what it had while verification loads. Once shown, it stays until the action settles, and clears in the same render as the action's own settled state. Render `prompt.content` inside a card; it covers a ready factor, a pending retry, and the unavailable state. Isolated panel stories below are for visual development only.

```tsx
import { Card } from '@clerk/mosaic/components/card';
import { useReverify } from '@clerk/mosaic/features/reverification';
import { useAction } from '@clerk/mosaic/hooks/useAction';

const { reverify, prompt } = useReverify();
const runAction = useAction(ctx => reverify(ctx, action));

{prompt ? <Card.Root renderBranding={false}>{prompt.content}</Card.Root> : null}
```
