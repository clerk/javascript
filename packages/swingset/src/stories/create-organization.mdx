# CreateOrganization

A card that creates an organization from a logo, a name, and a slug. The new organization becomes
the active one, and the card moves on to inviting members to it. **Skip** or **Finish** ends the flow
at `afterCreateOrganizationUrl`, or the instance's after-create URL when none is set.

It renders `fallback` while Clerk loads and nothing when nobody is signed in.

## Usage

```tsx
import { CreateOrganization } from '@clerk/mosaic';

<CreateOrganization />;
```

`afterCreateOrganizationUrl` takes a `:param` template, a plain path, or a function of the new
organization.

```tsx
<CreateOrganization afterCreateOrganizationUrl='/orgs/:slug' />
```

## Slug

Typing a name fills the slug from it: lowercase, with every run of other characters turned into a
hyphen. The slug can be edited, and only lowercase letters, numbers, and hyphens are accepted. When
the instance turns slugs off, the field is left out.

## Logo

**Upload** takes a PNG, JPEG, GIF, or WEBP image up to 10MB. The logo is set on the organization
once it is created. **Remove** clears the chosen logo before the organization is created.

## Errors

An error that names the name or the slug appears under that field. Any other error appears above the
form. Either way the form keeps its values.

<Story
  name='WithError'
  storyModule={CreateOrganizationStories}
/>

## Inviting members

The second step invites members to the new organization by email, with a role that starts on the
instance's default role. Sending the invitations shows a confirmation with **Finish**. The step is
skipped when `skipInvitationScreen` is set, or when the organization can hold only one member.
