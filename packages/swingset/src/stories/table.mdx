# Table

Table renders tabular data in a bordered Mosaic shell. It's composed from parts via dot syntax: `Table.Root` renders the `<table>` inside a shell that scrolls horizontally when the columns outgrow the container, and `Table.Header`, `Table.Body`, `Table.Row`, `Table.HeaderCell`, and `Table.Cell` map onto their native elements.

Sorting, selection, and the empty state are opt-in parts rather than state the table owns. Pair it with the [useDataTable](/hooks/use-data-table) hook, which holds sorting and row selection, and apply the sort to your rows before rendering them. Pagination is rendered by the consumer below the table with the Pagination component.

## Usage

```tsx
import { Table } from '@clerk/mosaic/components/table';

<>
  <Table.Toolbar>
    <Table.Search
      label='Search members'
      clearLabel='Clear search'
      value={search}
      onValueChange={setSearch}
    />
  </Table.Toolbar>

  <Table.Root>
    <Table.Header>
      <Table.Row>
        <Table.HeaderCell>Name</Table.HeaderCell>
        <Table.HeaderCell>Created</Table.HeaderCell>
      </Table.Row>
    </Table.Header>
    <Table.Body>
      {rows.map(row => (
        <Table.Row key={row.id}>
          <Table.Cell>{row.name}</Table.Cell>
          <Table.Cell noWrap>{row.created}</Table.Cell>
        </Table.Row>
      ))}
    </Table.Body>
  </Table.Root>
</>;
```

## Parts

- `Table.Toolbar` wraps search and optional actions in a responsive row. Render it before `Table.Root`, outside the table.
- `Table.Search` composes [InputGroup](/components/input-group), [Icon](/components/icon), and [Button](/components/button). Supply the controlled `value`, `onValueChange`, and localized `label` and `clearLabel`. Clearing returns focus to the input. Its `ref`, `xstyle`, and input props apply to the search input; `placeholder` defaults to `label`. The caller owns filtering and any debounce.
- `Table.Root` renders the `<table>`. `xstyle`, `ref`, and any table props land on it; the scrolling shell around it is internal.
- `Table.Header` and `Table.Body` render `<thead>` and `<tbody>`. Rows inside the body get a top border.
- `Table.Row` renders a `<tr>`. Pass `selected` to mark it `aria-selected` and tint it.
- `Table.HeaderCell` renders a `<th scope="col">`. Pass `onSort` to make it sortable: the label becomes a button with a direction icon, and `sort` (`'ascending'`, `'descending'`, or `'none'`) reflects the current direction as `aria-sort`. `align` moves the content to `'center'` or `'end'`.
- `Table.Cell` renders a `<td>` with the same `align` prop. `noWrap` defaults to `false`; enable it to keep dates and other short values on one line.
- `Table.SelectAllCell` and `Table.SelectCell` render a narrow header or body cell holding a [Checkbox](/components/checkbox). They take Checkbox props, so pass `checked`, `indeterminate`, and an `aria-label`. `Table.SelectCell` also takes `onToggleSelected`, called with `{ range: true }` when the checkbox was shift-clicked, which fits the row's `toggleSelected` from `useDataTable` directly.
- `Table.Empty` renders a full-width row with a single cell that spans every column. Put an [EmptyState](/components/empty-state) inside it. The cell uses the largest `colSpan` browsers allow, which stretches across the columns the table actually has; pass `colSpan` yourself if you need the exact count.

## Styling

Each part carries a stable `.cl-*` class, and the parts with state reflect it as `data-*` attributes:

| Class                   | Part                                      | Attributes                                                                                                                |
| ----------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `.cl-table-shell`       | The bordered wrapper around the table     |                                                                                                                           |
| `.cl-table-viewport`    | The horizontally scrolling viewport       |                                                                                                                           |
| `.cl-table`             | `Table.Root`                              |                                                                                                                           |
| `.cl-table-toolbar`     | `Table.Toolbar`                           |                                                                                                                           |
| `.cl-table-search`      | `Table.Search` input group                |                                                                                                                           |
| `.cl-table-header`      | `Table.Header`                            |                                                                                                                           |
| `.cl-table-body`        | `Table.Body`                              |                                                                                                                           |
| `.cl-table-row`         | `Table.Row`                               | `data-selected` when `selected`                                                                                           |
| `.cl-table-header-cell` | `Table.HeaderCell`                        | `data-align` (`start` / `center` / `end`), `data-sortable` when `onSort` is set, `data-sort` (`ascending` / `descending`) |
| `.cl-table-cell`        | `Table.Cell`                              | `data-align` (`start` / `center` / `end`), `data-no-wrap` when `noWrap`                                                   |
| `.cl-table-select-cell` | `Table.SelectAllCell`, `Table.SelectCell` |                                                                                                                           |
| `.cl-table-empty`       | `Table.Empty`                             |                                                                                                                           |

```css
.cl-table-row[data-selected] {
  background: rgba(0, 0, 0, 0.06);
}
```
