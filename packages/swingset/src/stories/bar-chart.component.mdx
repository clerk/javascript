# BarChart

A stacked bar chart with values above and below zero, built on the headless
[`Chart` primitive](/primitives/chart). Pass rows, a category key and a list of series, and it
draws the legend, a dotted grid, the bars, both axes, a hover band behind the bars and a tooltip. It
inherits the primitive's pointer and keyboard selection and its announcements.

`showLegend` defaults to on with two or more series or a labelled projection. `xTicks='calendar'`
expects UTC date keys. With `interactive={false}` the chart takes no selection, shows no tooltip and
has no tab stop, and the selection props do not type-check.

## Usage

<Usage
  component='BarChart'
  module='@clerk/mosaic/components/bar-chart'
  props={{ 'aria-label': 'Weekly growth' }}
/>

Each series names its color: a palette slot from `1` to `6`, which reads `--cl-color-chart-<n>`, or
any CSS color. The legend, the bars and the tooltip read that one field, so filtering the list never
recolors the series that remain. Define `series` and `index` at module level or memoize them.

```tsx
import { BarChart } from '@clerk/mosaic/components/bar-chart';
import type { ChartSeries } from '@clerk/mosaic/components/chart';

const series: ChartSeries<Week>[] = [
  { key: 'signups', label: 'Sign-ups', color: 1, value: week => week.signups },
  { key: 'returning', label: 'Returning', color: 2, value: week => week.returning },
  { key: 'churned', label: 'Churned', color: 3, value: week => week.churned },
];
const getWeek = (week: Week) => week.week;

<BarChart
  aria-label='Weekly growth'
  data={weeks}
  index={getWeek}
  series={series}
  xTicks='calendar'
/>;
```

To place the legend elsewhere, such as beside an Export button, pass `showLegend={false}` and render
`Chart.Legend items={series}` from `@clerk/mosaic/components/chart`. To add a total or a banner to the
tooltip, return `Chart.TooltipContent` from `renderTooltip`.

## Examples

### Palette

The six slots in order. They pass the data-viz contrast and color-blind checks against the surface
in light and dark mode for neighbours in this order. Avoid slot 2 beside 4, 2 beside 6 and 3 beside 5
in one stack.

### Highlight

`highlight` keeps the matching bars at full strength and dims the rest with an opaque mix toward
`--cl-color-surface`, so grid lines never show through. Here the selection drives it. Without
`highlight`, hovering shows the band and tooltip and dims nothing.

  name='Highlight'
  storyModule={BarChartStories}

### Projection

A projected total for one row, drawn as an opaque neutral fill with a dashed outline when it rises
above the row's stack. A `label` adds it to the legend and the tooltip.

### Empty

Without rows the chart shows an `EmptyState` over the plot and sets `data-state="empty"`. Replace it
with `renderEmptyState`. Loading is the owner's: render a `Skeleton` of the same `height`.

### Render error

When the Canvas cannot paint, the chart sets `data-state="error"`, calls `onRenderError` and offers a
retry that mounts a fresh Canvas.
