# UserProfileApiKeysPanel

The API keys panel lists the keys that belong to the signed-in user under the panel title. It renders `APIKeysTable` with the signed-in user as the subject.

### Loading

`APIKeysTableView` takes `skeleton` for its first load. Render it with placeholder keys (`APIKeysTableSkeleton` uses three) and the toolbar, column headers and rows draw as [Skeleton](/components/skeleton)s; wrap the panel title in `Skeleton` too. Keep the same view mounted and flip `skeleton` when the keys arrive. When to show it, and for how long, is up to the caller.

<Story name='Loading' storyModule={Stories} />

### Page change

With `refetchSkeleton`, the table turns its rows into placeholders while `isFetching` is set, and keeps its headers and controls. After a page change or a sort it shows exactly as many rows as the next page holds; after a search it shows three. This example takes 2s to fetch a page; go to page 2.
