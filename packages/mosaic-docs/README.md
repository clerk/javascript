# Mosaic docs

The documentation site for [`@clerk/mosaic`](../mosaic), Clerk's component library.

## Development

From the repository root:

```sh
pnpm dev:mosaic-docs
```

This builds `@clerk/mosaic` and starts the site at http://localhost:6021.
